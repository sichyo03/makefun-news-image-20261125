One image that sums up the world's news of **Wednesday, 25 November 2026**:
an illustrated newspaper front page, drawn with code (Python + PIL, flat
original art, no borrowed photos). The date is printed under the masthead,
the lead story carries the largest illustration, and four more stories fill
a 2×2 grid — five stories across conflict, markets, science and sport.

## The day's five stories

1. **Tankers hit mines in the Strait of Hormuz** — Iran's Revolutionary
   Guards say two oil tankers struck mines in the strait.
2. **Ukraine sinks a Russian warship** — naval drones sink the corvette
   *Merkury* in a Libyan port.
3. **AI stocks tumble; Nvidia falls** — Japan's Nikkei drops 2.8% as doubts
   about the AI boom hit markets.
4. **Pakistan's first astronaut in orbit** — reaches China's space station.
5. **Senegal regain the Africa Cup** — Senegal take back the Africa Cup of
   Nations title.

## Files

- `entry.png` — the front page (1024×1024 PNG).
- `draw_frontpage.py` — the script that draws `entry.png`.
- `main.ts` — copies `entry.png` to the output and verifies the bytes.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
